# MS7 Football Manager RC8.4

Fokus build ini:
- memperbaiki scroll PC + HP landscape,
- meningkatkan gesture/touch scrolling,
- memasang background music dari UploadThing,
- autoplay best-effort + fallback pada interaksi pertama,
- tombol Music ON/OFF di topbar.

Deploy `index.html`, `manifest.webmanifest`, dan `sw.js` ke root GitHub Pages.

## RC8.7 — Local Music
Background music sekarang menggunakan file lokal `music/ms7-football-manager-theme.mp3`. Tidak ada dependency URL UploadThing untuk musik aktif. Upload folder `music` bersama file app lainnya saat deploy ke GitHub Pages.
