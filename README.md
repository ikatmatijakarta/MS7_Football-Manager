# MS7 Football Manager RC6.1

RC6.1 mempertahankan Season Calendar Automation, landscape-first mobile UI, visual refresh, dan touch optimization dari RC6.

Default kickoff kalender musim diubah menjadi:
- Slot 1: **20:00 WIB**
- Slot 2: **22:10 WIB**

Admin tetap dapat mengubah kedua slot sebelum menekan Generate Calendar.

Jika kalender sudah dibuat tetapi belum aktif, tekan **Regenerate Preview** setelah update. Jika kalender sudah aktif / pertandingan sudah dimulai, file ini tidak mengubah jadwal aktif secara otomatis.
