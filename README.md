# MS7 Football Manager RC7.1

Versi ini meneruskan RC6.2/RC7 dan menambahkan visual live match 2D yang lebih detail.

## Isi utama
- `index.html` — frontend RC7.1.
- `manifest.webmanifest` — PWA landscape.
- `sw.js` — cache key RC7.1.
- `MS7_SEASON_CALENDAR_AUTOMATION_V1_2.sql` — patch Season Calendar / schedule sync yang tetap dipertahankan.
- `RC7_1_CHANGELOG_ID.md` — catatan perubahan.
- `RC7_1_DEPLOY_TEST_ID.md` — langkah deploy dan test.

## Fitur RC7.1
- 2D Live Match berbasis Canvas.
- Pitch hijau natural.
- Mini jersey untuk 22 pemain.
- Attack channel visual + ball trail + goal pulse.
- Render dibatasi sekitar 30 FPS supaya ringan di HP landscape.
- Match tetap server-authoritative.
